# Student Grade Calculator

## About the Project
Student Grade Calculator is a simple C++ console-based application
that calculates a student's total marks, percentage, and grade
based on marks obtained in three subjects.

This project was created to demonstrate basic C++ programming
and Git/GitHub version control operations.

## Features
- Accepts the student's name.
- Takes marks for three subjects as input.
- Calculates total marks.
- Calculates percentage.
- Assigns a grade based on the percentage.
- Displays the final result.

## Grading System

| Percentage | Grade |
|------------|-------|
| 90% and above | A+ |
| 80% - 89% | A |
| 70% - 79% | B |
| 60% - 69% | C |
| 40% - 59% | D |
| Below 40% | F (Fail) |
